# Gatekeeper: staged prompts for Cursor

Do NOT paste the whole handoff and ask for everything. Build in small slices, each with an acceptance check, and commit after each one.

## Stage 0 (you, about 10 minutes, no Cursor needed)

1. `agora login`, then `agora init gatekeeper --template nextjs`, `pnpm install`, `pnpm dev`. Open http://localhost:3000, click Start conversation, and confirm you can talk to the agent. Run `agora project doctor` if not.
2. `git init` (or use the generated repo), make a first commit. Confirm `.gitignore` covers every `.env*` file.
3. Copy `GATEKEEPER_HANDOFF.md` and `CURSOR_PROMPTS.md` into the repo root. Put `sie.mdc` in `.cursor/rules/`.
4. Add `.cursor/mcp.json` with the Agora docs MCP:
   ```json
   { "mcpServers": { "agora-docs": { "url": "https://mcp.agora.io" } } }
   ```
5. Add an `AGENTS.md` containing:
   ```
   ## Agora Documentation
   Agora documentation is updated frequently. Always use the agora-docs MCP before writing or changing Agora code. If it is not installed, tell me to install https://mcp.agora.io.

   ## Project spec
   GATEKEEPER_HANDOFF.md is the spec. Later sections override earlier ones: 27 > 26 > 25 > 23 > 20 > 19 > the rest. If two sections conflict, follow the later one and mention the conflict.
   ```
6. Add the Statsig MCP only if you decide to do Statsig later.

## Rules to include in EVERY prompt (paste at the end)

```
Rules:
- Make small, reviewable changes. Do not touch unrelated starter code.
- Never invent API fields. If docs (agora-docs MCP, sie.mdc pages) don't confirm something, leave TODO(VERIFY) and log the raw response.
- No new dependencies without listing them first.
- Never log or commit secrets. Keep keys on the server.
- Run the typecheck/build and fix errors before you finish.
- End with: what changed (files), how to test it in under 2 minutes, and anything still unverified.
```

## Prompt 2: Slice A (store, Grandma, tools)

```

- In-memory session store as a globalThis singleton so it survives hot reload (section 27).

Acceptance: I start a conversation, say "Grandma, it's me, I'm in jail and need money," and the server logs a requestVerification call with its arguments; checkStatus returns guidance.
```
